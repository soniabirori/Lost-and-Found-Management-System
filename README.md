**Lost and Found Management System**

Description

A web-based system that helps users report lost items, report found items, search items, and track item recovery.

**Features**

User Registration and Login

Report Lost Items

Report Found Items

Upload Item Photos

Search and Filter Items

Contact Item Owner

Update Item Status


**Technologies**

ASP.NET Web Forms

C#

SQL Server
